# ACML 2026 Tutorial Website

Static GitHub Pages website for **Advances in Multi-Modal Time Series: From Forecasting to Reasoning**.

## Structure

- `index.html` — single-page tutorial website
- `assets/style.css` — visual styling

The content organization is inspired by the AJCAI tutorial format: event details, abstract, timed tutorial outline, presenter information, then practical materials / datasets / demo code / slides / recording.

## Publish

Upload the contents of this folder to the repository root. In GitHub **Settings → Pages**, deploy from `main` and `/ (root)`.
